# Aman Tariq | Portfolio

**Live site:** https://amantariq1.github.io/aman-tariq-portfolio-v2/

## What's on the site

- **Home:** introduction and a short animation of how my RAG-based AI Assistant works
- **About:** background, education and quick facts
- **Skills:** web development, AI/ML, programming languages, databases and tools
- **Projects:** General AI Assistant with dynamic RAG, AI Humorous Chatbot, websites and WooCommerce stores
- **Experience and training:** UAJK, web development internship at AJK IT Board, and courses at AJK IT Excellence Center
- **Contact:** email, GitHub, LinkedIn and a message form (opens your email app)

## Featured project

**General AI Assistant with dynamic RAG** is a chatbot that talks normally with a language model and switches to answering from your own documents when you upload a PDF, Word or text file. Documents are extracted, chunked, embedded and stored in a vector database, and the most relevant passages are retrieved to ground each answer.

## Run it locally

No installation needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/AmanTariq1/aman-tariq-portfolio-v2.git
   cd aman-tariq-portfolio-v2
   ```
2. Open `index.html` in your browser.

## Updating the site

- To change text, projects or skills, edit `index.html`.
- To update the CV, replace `Aman_Tariq_CV.pdf` and keep the same file name.
- After you commit and push, GitHub Pages republishes the site within a minute or two.
